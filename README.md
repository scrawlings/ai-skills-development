# ai-skills-development

A record of various skills that I've been tinkering with.

- [coding-skills](coding-skills) is a work in progress set of skills to guide a software development workflow, I have two main goal: 
    - Capture the things that I think deliver the most value in an incremental test driven development process, make ceremony and structure in planning earn its keep, including coding style guides that provide actionable direction toward code structure that supports ongoing work in the code base, and my strong bias to genuine test first style as a driver of module and interface design.
    - (Early days), express a process or workflow that supports an exploratory development process, starting with unclear and requirements that are likely to change, while keeping a clean and working code base. This is a much less common type of software development process (we humans mostly go ad hoc and often have the programmer as domain expert when the goals are very fuzzy). I'm just trying to codify that in a way that fits with AI development. 
- [disciplined-research](skills/disciplined-research/SKILL.md) two things came together, news stories of government reports and academic papers where naive use of AI produced bad results, and some research of my own getting variable results. I wanted a skill that guide results and guide the researcher to look deeper and work in a serious and professional way with citation focused research work.
    - This skill can be applied retro-actively to session that involved research and in my first use of it that way it picked up a real fabricated attribution (the paper was real and critical). It also picked up weaker problems like language __"the literature shows X" — they're each "one study found X"__.
    - If you don't know how to formally install a skill, you can just copy the text of this one and paste it into a session. __Do it, it's important!__
    - Also ask it to produce a HTML summary with the checked references linked and the click through them yourself, check that the paper does match, but you still get the AI to make that work easier you.
    - Software developers, consider having a skills in your software development workflow that gets the agent to check against the latest documentation and not just what it might have been trained on. This attribution problem has parallels in coding as well and is probably behind the sometimes weird versions of libraries the AI agents can choose.
- [fiction-framework](fiction-framework) is a bunch of tools I've exploring to support writing fiction, particularly thinking about fantasy and science-fiction, with a process of note taking and idea exploration to support clarity and focus when I want to write. 
    - [world-bible](fiction-framework/world-bible/SKILL.md) is the starting place — it defines the schema and conventions (world/canon/, truth format, status tags, index) that every other world skill depends on. Load it first before [world-build](fiction-framework/world-build/SKILL.md) (add new truths), [world-refine](fiction-framework/world-refine/SKILL.md) (tighten existing ones), [world-probe](fiction-framework/world-probe/SKILL.md) (generate questions), or [canon-check](fiction-framework/canon-check/SKILL.md) (validate against canon).
    - Working with this for a little while has me wanting to change lots of details, so I expect this will evolve or have superceeding versions in future.
